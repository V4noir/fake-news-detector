# 📰 Fake News Detector with Deep Learning

A deep learning project built with **TensorFlow / Keras** that classifies news articles as real or fake based on textual features.

## 🚀 Features

- Text preprocessing and tokenization pipeline
- Binary classification model trained with Keras deep neural network architecture
- Exported native `.keras` model artifact for fast inference
- Clean separation of training (`main.py`) and inference logic

## 📦 Tech Stack

- **Python 3.10+**
- **TensorFlow / Keras**
- **Pandas**
- **NumPy**
